ToggleTax

Shopify Theme App Extension

ToggleTax adds a simple toggle widget to your Shopify store that lets customers switch between tax-inclusive and tax-exclusive prices — on product pages and in the cart.

No backend. No servers. Works entirely in the browser using your theme's existing price elements.

How to set up

  1. Install the app from the Shopify App Store.
  2. Go to Online Store → Themes → Customise.
  3. Open any product page in the editor.
  4. Click Add block → Apps → Tax Toggle.
  5. Set your tax rate (e.g. 20 for 20% VAT / GST).
  6. Toggle "Theme base prices include tax" if your Shopify prices already include tax.
  7. Save. Done.

What it does

  • Displays a toggle (Excl. Tax / Incl. Tax) on the product page
  • Automatically updates all matching price elements on the page
  • Auto-injects the toggle into cart drawer / cart page too
  • Remembers the customer's preference across pages
  • Works with any Shopify theme — no code changes required

Compatibility

Works with any country's tax system — VAT (UK, EU), GST (Australia, New Zealand), Sales Tax, or any fixed-rate tax. The tax rate is fully configurable.
